# 实现结构

产品聚焦 CATIA V5 手册查看、搜索与来源导航。核心仅依赖 Python 服务层，GUI 使用 PySide6 Widgets 和 Qt WebEngine；不依赖 CATIA 帮助宏或外部数据库服务器。

## 文档与来源

`core/parser.py` 解析旧 HTML、框架和编码，恢复可静态识别的旧式链接。渲染保留图片、表格、链接与锚点，移除原文脚本及活动内容。本地文件访问通过文档根目录与资源类型校验。

文档库 UUID 与安装路径分离，文章使用库身份和相对路径生成稳定 ID。`SourceLocation` 记录原文哈希、段落、锚点及引用文本，供检索、翻译、历史与图视图共用。原文变化时按锚点、标题和上下文重定位，歧义会明确返回。详见 [来源契约](library-contract.md)。

## 搜索

SQLite 保存正文、分块、FTS5、目录收录、命令、关键词与元数据。检索优先处理明确命令和页名，再综合标题、章节与正文；按文章合并并保留命中来源，分类范围在查询阶段生效。

内置双语命令词库来自开发机资源提取，运行时不读取 CATIA 安装目录；用户别名单独保存。可选 multilingual-e5-small 本地语义检索与关键词结果融合，模型和向量规格单独标记；不因搬迁路径改变模型内容身份。

## 翻译与阅读

服务配置与 provider 分离，API Key 使用当前 Windows 用户的 DPAPI 加密。选词翻译有延迟与长度限制，后台执行并丢弃过期结果。

整页按段落生成任务，优先处理视口附近内容；原文、双语、中文复用同一 DOM 与来源标记。缓存按提供方、模型内容修订、目标语言和原文区分；暂停、重试及模式切换保留已有译文与阅读位置。

## 界面与资源

统一阅读状态管理跨页阅读模式、侧栏与历史。状态栏集中显示任务、翻译服务和错误。能力检测控制示例打开；文件定位与图片预览不依赖 CATIA。

`gui/function_map.py` 管理原生画布，`gui/graph_geometry.py` 负责布局与有工作上限的避障路由，`gui/graph_edge.py` 绘制圆角连线和按焦点显示的标签。自由平移不以内容边界为限，节点拖动仅调整显示布局。

功能地图投影已有目录；页面关系图只使用原文链接、图片和可核对的命令标识。语义边与排版发现边分离，循环引用保留方向。默认最多 80 个节点，硬上限 200，逐级展开每组 20 项；不绘制全库网络。布局与视口单独保存，前进后退恢复查看状态。

## 数据与分发

SQLite backup API 生成包含已提交 WAL 的一致快照。迁移包包含配置、数据库和可选文档/模型，每个文件记录大小与 SHA-256。导入先校验路径、内容、库身份和文档完整清单，再在新目录挂载，不覆盖原库。密钥、CATIA 安装路径、日志与渲染缓存不导出。

Nuitka 生成 Windows x64 便携目录。发行默认值与个人配置隔离；GitHub CI 仅构建、打包和校验公开制品，不运行测试，不收集开发机数据。
