# B 轮：文档库、来源位置与关键词检索

## 使用入口

本轮在便携应用的“更多（…）”中增加 **文档库管理** 和 **术语与别名**，不增加使用者启动方式。首次使用旧索引时自动升级；要获得完整内容清单及新版章节信息，请执行一次不限定范围的“更新文档索引”。

迁移到其他电脑时：

1. 复制整个便携目录及手册副本，在新电脑选择可用的文档目录。
2. 打开“文档库管理”，选择待验证的副本目录，再选择携带的原索引或导出快照。
3. 软件完整校验文档、图片、示例和其他资源；一致时可“复制并复用索引”。挂载会生成新数据库，不改绑或覆盖原数据库。
4. 存在差异时显示新增、删除和修改文件。只有确认属于同库修订才勾选确认继续，随后完整更新索引；不同版本或语言应通过设置登记为新库。

复用保留库 UUID、文章 ID、用户别名、阅读位置和翻译缓存。直接在设置中切换根目录仍保留原有隔离行为，不会按目录名猜测同库。读取原库不要求原手册仍在旧磁盘；副本验证使用数据库中保存的清单。

## 核心实现

| 部分 | 实现与职责 |
| --- | --- |
| library_contract.py | v1 库身份、DocumentRef、SourceLocation，标准库类型与 JSON 校验 |
| library.py | 全文件 SHA-256 清单、差异比较、SQLite 一致快照、显式副本挂载 |
| source.py | 文本块与标题层级提取、DOM 来源标记、修订后重定位 |
| index_schema.py / index.py | schema 2 事务升级、章节 FTS、用户术语、阅读来源与增量更新 |
| query.py / search.py | 中文术语与操作表达展开、范围别名、加权检索及可解释回退 |
| gui/library.py | 后台验证、快照与术语管理，文件扫描不阻塞界面 |

数据契约详见 [文档库与来源位置](library-contract.md)。库身份与机器根目录分离，文档 ID 由库 UUID 和规范化相对路径生成。增量更新比较原始内容哈希，mtime 变化不强迫重解析，大小和 mtime 相同也不能掩盖实际内容变化。分类标签变化仅刷新分块的检索上下文；用户别名实时用于查询，不需要重建。

清单必须完整扫描成功才能验证。部分模块、有限页数或任何扫描错误都不会生成可复用的已验证清单。手册自带的 `.db` 等资源照常参与校验；应用自己的数据库、WAL/SHM、渲染缓存和备份路径作为明确的相对排除项记录。扫描遇到不可访问目录、链接目录、大小写或 Unicode 冲突会失败，不静默遗漏。

## 来源与阅读位置

搜索结果包含文章 ID、标题层级、原文内容哈希、块 ID、锚点、引用文本及命中依据。点击结果先核对原文，再滚动到相应章节；历史和跨重启阅读位置使用同一来源格式。来源 DOM 标记只包装文本，不搬动图片、表格、链接或原有锚点。阅读模式仍使用全局偏好。

重定位返回明确状态：

| 状态 | 行为 |
| --- | --- |
| exact | 原文哈希相同，匹配块 ID，恢复相对视口偏移 |
| anchor / relocated-anchor | 显式锚点或修订后仍存在的原锚点 |
| relocated-quote | 按引用、标题路径和前后文找到唯一候选 |
| document | 仅引用文章，打开文章入口 |
| ambiguous | 多个候选无法区分，不任意选择其中一个 |
| missing | 文件或来源内容不存在，提示后保留当前阅读页 |

旧来源来自不同库 UUID 时明确拒绝。正文渲染内存缓存也按内容哈希识别修订；frameset 的入口缓存不能遮蔽主页面变化。阅读位置防抖保存于 reader_locations，重建文档和分块不会删除阅读位置或用户术语，也不会清理其他用户表。

## 搜索能力与边界

SQLite FTS5 对原文分块建立 title、heading、keywords、body 四个字段，按标题、章节、分类或文件名、正文依次加权。关键词上下文包括功能手册名称、文档名和示例名称。结果按文章聚合后限量，避免一篇长文挤占结果；模块／分类限制在候选检索阶段生效。

中文使用本地 CAD 术语、命令别名和常见操作表达展开，例如“终止面”“矩形阵列”“对称拉伸”。用户可添加全局或指定手册的名称；手册范围也适用于包含该手册的分类。未覆盖的中文会保留为未知概念，已有翻译服务可扩展查询，不能悄悄丢词产生误导结果。

优先查找同一章节全部概念，其次查找同篇文章不同章节全部概念，再显式返回达到覆盖阈值的部分概念结果。英文无结果时可基于词汇索引尝试拼写建议；界面说明回退方式，CLI 的 `--explain` 提供完整计划。严格匹配、跨章节匹配、部分匹配与拼写回退均保留原文来源。

本轮没有整库中文译文索引、向量模型、语义重排或图谱。术语展开不能保证理解任意中文问题；这些检索通道在后续轮次加入，继续复用同一库与来源契约。

## 升级与缓存

schema 1 升级前使用 SQLite backup API 在索引旁的 `backups` 创建唯一备份，包含已提交 WAL。升级在事务中创建新结构并回填可用旧数据，保留原文、用户表与缓存；完整更新后补齐新版章节与清单。未知的更高 schema 版本明确拒绝打开。

快照与挂载目标必须是新文件，不能覆盖已有数据库。挂载再次完整验证副本，并确认快照仍来自同一已验证清单。明确接受的修订暂标记未验证，成功完整更新后再建立新清单。

离线模型 provider 使用模型内容修订作为身份，不包含模型安装路径。升级时迁移旧的路径相关缓存标识并保留旧行，整页与选词缓存都可继续复用；目标语言、模型修订、原文和上下文指纹仍参与缓存隔离。
