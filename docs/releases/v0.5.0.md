# Catia Manual Viewer v0.5.0

首个 GitHub Release，提供 Windows x64 便携版，包含英文 ↔ 中文离线模型。解压整个 ZIP 后运行 `CatiaManualViewer.exe`，无需安装 Python。

## 功能

- 按 CATIA 功能分类浏览手册，支持分类或手册范围搜索及中文查询。
- 原文、双语、中文三种阅读模式；逐段翻译、视口优先、缓存、暂停和失败重试。
- 选词及句子即译，可配置本机模型、MyMemory、DeepL、LibreTranslate 或兼容的大模型 API。
- 保留图片、链接、锚点、代码和阅读位置，支持历史记录及鼠标侧键。
- 导出 CATIA 帮助宏；Pad / Pocket 主题定位、工作台范围搜索及已有窗口复用。

## 开始使用

1. 解压到可写目录，保留所有 DLL、QtWebEngine 资源及模型文件。
2. 首次启动时选择包含 `online` 文件夹的 CATIA 英文文档根目录。
3. 通过“更多 → 更新文档索引”建立搜索索引。
4. 根据需要设置 CATIA 启动路径和翻译服务。宏安装步骤见随包的 `CATIA宏安装说明.txt`。

资产中的 `.zip.sha256` 可用于校验 ZIP。软件不包含 CATIA 程序、原版手册、个人索引或 API Key。

## 已知边界

- 离线通用模型仍可能误译 CAD 句子，建议先使用双语对照；图片内文字不做 OCR。
- 中文模式保留原始链接名称和代码。中文搜索尚未使用整库译文索引。
- 帮助宏按工作台和选中特征定位；精确映射目前覆盖 Pad、Pocket，其他情况降级搜索。
- 仅构建 Windows x64；未进行代码签名。CATIA 示例打开和宏入口需要本机安装 CATIA。
