# Catia Manual Viewer v0.8.0

- 修复便携版界面启动 MCP 后台服务的问题，完善进程启动及生命周期管理。
- MCP 启动失败现在显示具体错误类别，并在调用日志中记录错误类型和退出码，便于区分进程、依赖、索引和监听故障；不记录令牌或手册正文。
- 新增 Google 翻译（实验），无需 API Key，支持划词即译及整页原文／双语／中文模式，复用缓存、渐进加载、暂停和重试。
- Google 请求按长度分段并统一限速；接口受限或失败时保留明确错误，允许暂停后重试或切换服务。此网页接口不保证长期免费、额度或可用性。
- 修复便携版 HTTPS 证书资源定位，在线翻译保留证书验证，运行诊断可离线检查客户端是否正常初始化。

完整解压 Windows x64 便携 ZIP 后运行 CatiaManualViewer.exe。翻译服务可在“设置 → 翻译”中选择；现有翻译设置不会自动切换。

升级前关闭旧版，保留 config.local.toml 及其指定的数据目录。已有索引可继续使用，无需重新建立。

发行包包含离线翻译模型，不包含个人设置、调用日志、索引、CATIA 程序或原版手册。
