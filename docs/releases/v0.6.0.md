# Catia Manual Viewer v0.6.0

- 完善中英文命令与关键词检索、功能分类和原文定位。
- 支持原文／双语／中文渐进阅读、缓存、暂停与重试。
- 增加功能地图与有原文依据的页面关系图，支持自由画布、节点拖动、连线聚焦和视图恢复。
- 完善图片预览、示例双击打开、文件定位、能力检测与设置持久化。
- 增加设置与数据迁移包，可携带索引、缓存、阅读状态、文档副本和模型。
- 精简仓库文档与开发工具，统一程序、包和发布标签版本。

完整解压便携 ZIP 后运行 CatiaManualViewer.exe。API Key 不随迁移包导出；CATIA 程序与原版手册不在公开发行包中。
