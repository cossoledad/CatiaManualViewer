# Catia Manual Viewer v0.7.0

- 增加本机及局域网只读 MCP 服务，支持 Codex 等客户端发现文档库、按功能范围检索、逐段读取原文、浏览目录和校验来源。
- 默认免令牌连接，适配 Windows／WSL；可选令牌验证、网段限制及随软件启动。切换文档库需重新授权，关闭软件自动停止服务。
- 增加 MCP 调用日志及界面入口，记录工具、耗时、状态、结果数量和错误码。日志自动轮转，不记录令牌、调用参数、搜索词或手册正文。
- 统一便携版内的服务入口及运行依赖；客户端无需安装 Python、CATIA 或复制文档。

完整解压 Windows x64 便携 ZIP 后运行 CatiaManualViewer.exe。首次建立索引后，在“更多 → Agent 接入”启动服务并复制 Codex 配置。

从旧的令牌配置切换为免令牌模式时，删除 Codex 中 `catia_manual` 的 `bearer_token_env_var` 配置并重启客户端。

发行包包含离线翻译模型，不包含个人设置、调用日志、索引、CATIA 程序或原版手册。API Key 与 Agent 连接配置不随迁移包导出。
