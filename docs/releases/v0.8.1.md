# Catia Manual Viewer v0.8.1

- 正文工具栏新增“打印当前页到 PDF”（Ctrl+P），按当前原文／双语／中文模式导出整篇文章，保留图片与链接；未完成翻译的段落保留当前显示内容。
- PDF 使用独立页面快照生成，导出时仍可继续阅读。文件写入失败不会覆盖已有文件，完成和错误状态显示在底栏。
- 新增系统托盘入口。默认点击窗口最小化按钮即隐藏到托盘，也可使用“更多 → 最小化到系统托盘”或 Ctrl+Shift+M；MCP 与后台任务继续运行。
- 点击托盘图标或重新打开软件恢复原窗口；托盘右键菜单可显示窗口、打开 Agent 接入或退出。关闭窗口和托盘“退出”都会正常停止 MCP 并保存状态。
- “设置 → 阅读与界面”可关闭最小化到托盘；系统托盘不可用时保留普通最小化，避免窗口无法找回。

完整解压 Windows x64 便携 ZIP 后运行 CatiaManualViewer.exe。升级前退出旧版，保留 config.local.toml 及其指定的数据目录；已有索引无需重建。

发行包包含离线翻译模型，不包含个人配置、调用日志、索引、CATIA 程序或原版手册。
