# Catia Manual Viewer v0.8.2

- 新增“分享当前页”。应用链接定位到文章、锚点及当前段落，不含本机路径，重启或迁移后仍可解析；内容一致的手册副本可跨库打开，版本不同会明确提示。
- “更多 → 打开分享链接”可粘贴应用或浏览器分享链接。分享窗口可关联当前用户的 Windows 应用链接，点击链接可启动查看器或唤醒已有窗口；移动便携版后重新关联即可。
- MCP 搜索、读取结果新增 `share_uri`，新增只读 `resolve_share(uri)` 工具，将持久链接解析为当前服务的读取标识，供 Agent 继续调用 `fetch`。
- 无令牌 Agent 服务运行时，可生成局域网浏览器分享链接；接收者无需安装软件即可阅读原文文字。图片、示例和翻译继续在桌面查看器中提供。分享沿用已有服务的网段、端口和访问控制，不自动开放服务或修改防火墙。
- 最小化改为普通任务栏最小化。关闭窗口时可选择留在系统托盘或退出，支持记住选择，并可在“阅读与界面”设置中修改；托盘中的 MCP 与后台任务继续运行。
- 托盘“退出”直接保存并停止服务；系统托盘不可用时保留正常退出行为。

完整解压 Windows x64 便携 ZIP 后运行 CatiaManualViewer.exe。升级前退出旧版，保留 config.local.toml 及其指定的数据目录；已有索引无需重建。旧的“最小化到托盘”偏好不再生效，首次关闭使用新的选择窗口。

发行包包含离线翻译模型，不包含个人配置、调用日志、索引、CATIA 程序或原版手册。
