# A 轮：阅读状态、资源交互与能力降级

## 当前实现

- 阅读模式由 Qt 无关的 ReaderState 管理，通过 appearance.reading_mode 保存；页面任务使用当前模式，不再以历史页面的旧模式覆盖用户选择。偏好变更防抖写入配置，侧栏分隔位置也保留。
- 阅读器保持同一 WebEngine 实例。切页期间用上一帧覆盖重绘，新页的模式、译文缓存及相对位置应用后再展示。首页和正文保持相同的工具栏、侧栏结构，标题和底栏长文本省略显示。
- StatusCenter 按来源、优先级和有效期协调导航、检索、索引与资源消息，错误不会被后台进度清掉；活动窗口保留有限的消息记录。常规失败不弹模态对话框。
- 资源操作由 ResourceService 与 GUI adapter 共用。正文与示例列表单击选择、双击打开，列表 Enter 可打开；同一示例的进行中请求去重。右键提供 CATIA 打开、资源管理器选中、路径复制；缺失与越界资源不能打开。
- 单击未承载其他链接的图片打开独立预览，可缩放、拖动、适应窗口、100% 和切换同页图片。带链接的图片保留原有链接，可通过右键预览；预览不进入正文历史。
- 能力检查不加载模型或访问 API，也不启动 CATIA。CATIA 会话使用后台 attach-only 探针；没有启动配置时可利用已运行会话。没有 CATIA 时禁用启动动作，定位、阅读、搜索、翻译仍独立可用。翻译配置不完整也可保存其他设置。

## 移除范围

已删除帮助宏生成与特征映射、导出菜单、专用启动参数和 IPC 字段、专用验证脚本与测试，以及发行说明资源和制品依赖。通用窗口激活只保留 open 与前置窗口。当前源码与新发行包不再提供 CATIA 内部帮助入口。

此前安装在本机 CATIA 的用户工具栏及目录库不会被程序自动改写。若仍有旧按钮，可在 CATIA“工具 → 自定义”中移除对应 Catia Manual Viewer 按钮或工具栏，在“工具 → 宏 → 宏库”中移除以前为查看器添加的目录；不要删除其他工具栏、宏库或整个 CATSettings。旧 EXE/ZIP 是历史制品，不由本轮源码变更自动替换。

## B 轮边界

已确定并提供 v1 文档库／来源位置类型及 JSON 往返，详见 [数据契约](library-contract.md)。A 轮完成时不执行索引迁移、整库内容清单、语义检索或知识图谱；迁移与关键词检索现已在 [B 轮](stage-b.md) 实现。

## 本机验收入口

```powershell
.venv\Scripts\python.exe -m pytest --basetemp=.cache/pytest-stage-a -q
.venv\Scripts\python.exe scripts/verify_stage_a_gui.py
.venv\Scripts\python.exe scripts/verify_stage5_gui.py
```

新增 GUI 验收使用构造手册和模拟外部服务，验证真实鼠标事件、能力降级、图片窗口、模式跨页与持久化、状态优先级；CATIA 与资源管理器调用被模拟，不修改模型或启动外部程序。报告与截图保存在忽略提交的 data 目录。既有整页验收继续验证视口优先、暂停重试、缓存、锚点及阅读位置。

本机结果：76 项核心测试、18 项 A 轮 GUI 验收与 14 项整页翻译回归通过。另通过 computer-use 在隔离的原生 Windows 窗口确认：正文链接真实双击只分发一次带中文和空格的路径、右键定位正确分发、图片可在独立窗口按原始比例显示，关闭后正文仍保留。外部 CATIA 与 Explorer 均为模拟调用，本轮没有打开真实模型。原手册脚本仍禁用，资源桥只在 ApplicationWorld 暴露，并校验页面 key 与库内目标。

CI 保持仅 Nuitka 编译、打包与制品校验；以上测试不加入 CI。新推理模型、自动生成图谱留待后续轮次；跨电脑索引复用见 B 轮实现。
