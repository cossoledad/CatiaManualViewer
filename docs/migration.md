# 设置与数据迁移

## 导出

在“更多 → 数据迁移 → 导出”保存 ZIP。默认包含文档副本与可用的本机模型；可按体积需要取消。

始终包含：翻译服务配置、界面偏好、完整 SQLite 数据库、全文与语义索引、译文缓存、自定义术语、阅读位置、功能地图与关系图布局。模型文件不在数据库中，需要勾选“包含本机模型”才能一并携带；未包含模型时导出配置切换到术语表和关键词搜索。

导出前需完成一次完整索引更新；文档变化或未验证时会提示重新更新。操作在后台进行，可取消。数据库使用一致快照，不需要复制 WAL/SHM。文档逐文件核对内容哈希，模型文件变化时中止导出。

不包含 API Key（包括 DPAPI 密文）、CATIA 程序与机器路径、浏览器渲染缓存、日志、下载临时文件或历史备份。迁移包属于个人文档数据，不是公开 Release 制品。

## 导入

1. 在目标电脑解压官方便携版并启动，进入“数据迁移 → 导入”。
2. 选择迁移 ZIP。若包未含文档，选择已有的文档副本。
3. 点击“导入并使用”。文件哈希、数据库、库身份和完整文档清单验证成功后，自动应用配置和数据。

如果首次启动尚未配置文档，可关闭设置窗口，再进入数据迁移。导入无须先建立空索引。

数据放入当前数据目录下新的 `imports/<标识>`，原数据库保持不变；当前配置备份保存在该目录的 `previous-config.toml`，它可能包含本机加密密钥，请按个人配置保管。导入失败会清理本次新目录，保持原配置。

密钥在目标电脑重新填写，CATIA 沿用目标电脑已有配置。没有 CATIA 不影响文档、搜索、翻译、地图、图片和文件定位；没有模型仍保留关键词搜索与术语表。

## 数据格式

ZIP 根目录有 `transfer.json`、`config.toml`、`data/library.sqlite3`；可选目录为 `manuals/English`、`data/models` 和 `data/search-models`。清单版本为 1，记录程序版本、文档库 UUID、原文清单哈希和每个文件的大小/SHA-256。导入拒绝目录穿越、重复路径、Windows 文件名冲突、链接和清单之外的内容，不执行包内文件。

`core/transfer.py` 独立于 GUI，复用 `core/library.py` 的快照和副本校验。导出 API 为 `export_bundle(settings, destination, include_documents=True, include_models=True)`；导入 API 为 `import_bundle(archive, new_directory, root=None)`。返回配置和数据路径，由调用方在成功后激活。
