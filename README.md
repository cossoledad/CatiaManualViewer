# Catia Manual Viewer

CATIA V5 本地文档桌面查看器：按功能分类浏览、范围搜索、选词 / 句子即译、示例文件跳转与浏览历史。Python 核心解析器独立于 GUI，保留供开发和未来 agent 集成的接口。

## 使用便携版

使用者只需解压发行 ZIP，双击目录中的 **CatiaManualViewer.exe**。无需安装 Python；请保留整个目录中的 DLL、WebEngine 资源及模型文件。

第一次启动自动打开设置，选择包含 `online` 文件夹的文档根目录，然后通过右上角“更多（…）→ 更新文档索引”建立搜索索引。文档副本可以放在其他磁盘，不需要安装 CATIA 才能阅读；打开模型示例需要配置本机 CATIA。

设置按钮直接打开全局设置（Ctrl+,），可修改文档与数据位置、CATIA、翻译服务和阅读外观。后退 / 前进是独立按钮，旁边的时钟按钮打开浏览记录；同时支持 Alt 方向键和鼠标侧键。

翻译框仅显示原文、译文和必要的 CAD 术语；服务、模型、缓存和处理状态显示在底部状态栏。

## 翻译与搜索

支持本机英中双向模型、离线术语表、MyMemory、DeepL、LibreTranslate 和兼容 Chat Completions 的大模型 API。非大模型源提供默认值；需要密钥的源仍需自行填写 Key，大模型另需填写地址与模型名。选中单词或句子后自动翻译，可在设置中测试服务。

API Key 只保存在本次进程，或读取指定环境变量，不写入 TOML。使用在线服务时，选中的文本及需要翻译的中文搜索词会发送给所选服务。纯 CAD 术语查询可在本地展开为英文搜索。当前中文搜索查询原文，尚未建立整库中文译文索引。

本轮发行包可选择是否包含离线模型。带模型版默认本机推理，不带模型版默认术语表；两者均可改用 API。整页翻译和 CATIA 内的帮助入口仍处于设计阶段，详见[第四阶段设计](docs/stage4.md)。

## 数据与迁移

程序目录需要可写。`config.default.toml` 是发行默认值，个人设置保存于 `config.local.toml`；默认 `data` 存放索引、翻译缓存、渲染缓存及可选模型。相对路径以配置文件目录为基准，编译版不读取当前工作目录中的其他配置。

迁移时复制整个便携目录，再在设置中选择新电脑上的文档及 CATIA 路径。若文档根目录改变，软件使用独立索引文件，请重新更新索引。发行包不包含 CATIA 安装文件、手册原文或本机个人配置。
