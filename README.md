# Catia Manual Viewer

CATIA V5 本地手册查看器。支持功能导航、中英文搜索、翻译、示例文件操作和图形导航；无需安装 CATIA 即可阅读文档。

## 使用

从 [Releases](https://github.com/cossoledad/CatiaManualViewer/releases) 下载 Windows x64 便携包，完整解压后运行 **CatiaManualViewer.exe**，无需安装 Python。

首次启动选择包含 `online` 文件夹的英文文档根目录，通过“更多 → 更新文档索引”建立搜索索引。CATIA 仅用于打开示例，可在设置中配置。

## 功能

- **阅读与导航**：按原手册功能分类浏览，支持锚点、浏览历史、鼠标侧键、匹配高亮与浏览器原文定位；阅读模式及界面偏好自动保存。
- **中英文搜索**：标题、章节、命令和原文关键词优先，支持分类范围、双语术语与自定义别名。可选本机语义检索；模型不可用时保留关键词搜索。
- **翻译**：划词即译，整页支持原文／双语／中文、渐进加载、缓存、暂停与重试。可用离线模型、术语表、MyMemory、DeepL、LibreTranslate 和兼容 Chat Completions 的 API。
- **文件与图片**：示例双击或 Enter 请求 CATIA 打开，右键定位文件；图片可独立预览、缩放和拖动。未安装 CATIA 时仍可定位与预览。
- **功能地图**：查看分类、手册、章节及同级操作；支持折叠、分页、聚焦分支和打开原文。
- **页面关系图**：以当前文章为中心，查看原文有依据的参考、页面、命令、示例与图片关系，支持逐级展开和出处跳转。
- **Agent 接入**：内置只读 MCP 服务，供本机或局域网中的 Codex 等客户端搜索、浏览和读取有来源的手册内容。

两种图均支持空白左拖、中键平移、节点拖动、指针缩放和整理布局；前进后退与重开恢复位置。图只辅助查看，不提供笔记或自定义关系编辑。

## 设置与迁移

“设置”统一管理文档、数据目录、CATIA、翻译与界面。“更多 → 数据迁移”可导出设置、完整数据库、索引、译文缓存、别名、阅读位置和图布局，可选包含文档副本与本机模型。

在另一台电脑解压官方便携版，打开“数据迁移 → 导入”，选择迁移包并使用。未包含文档的包需要指定已有文档副本；完整验证通过后复用索引，无需重新构建。导入使用新的数据目录，保留原数据库。详细内容见 [迁移说明](docs/migration.md)。

API Key 按 Windows 用户加密保存在本机，迁移包不包含密钥；在线翻译服务使用时会发送选中的文本或当前文章的待译段落。发行包不包含 CATIA、原版手册或个人数据。

## 开发

Python 核心与 Qt 界面分离。使用者统一通过便携版 EXE 启动；Agent 使用“更多 → Agent 接入”中的 MCP 服务，JSON CLI 保留用于开发。
